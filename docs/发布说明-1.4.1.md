# 天若 OCR 1.4.1 · Paddle 单引擎版

## 本次变化

- 移除 CL 引擎及其工程、模型、接口菜单和设置，普通与批量识别统一使用 Paddle。
- 默认模型升级至 PP-OCRv6 small，方向分类采用 PP-LCNet x0.25，ONNX Runtime 升级至 1.31.1。
- 支持模型动态输入尺寸、模型内置字典及类别数量校验，改进原生资源释放与模型切换同步。
- 修复 Paddle 框阈值保存问题，旧 CL 接口配置自动迁移到 Paddle。
- 清除上游遗留的硬编码默认接口凭据，不附带用户配置。
- 补充中文使用说明、架构图、模型校验脚本和可重复打包脚本。

## 下载与运行

下载 `天若OCR-Paddle单引擎版-1.4.1-win-x64.zip`，完整解压，运行其中的 `天若OCR文字识别.exe`。ZIP 已包含模型与应用依赖，普通运行不需要 Python。

运行环境：Windows x64、.NET Framework 4.7.2 或更高版本、Microsoft Visual C++ v14 x64 运行库。不保证 Windows 7 兼容，请勿混入旧版 ONNX 或 VC++ DLL。

`SHA256SUMS.txt` 用于核对成品 ZIP；ZIP 内的 `SHA256.json` 可核对逐文件内容。源码请使用本标签对应的 GitHub Source code 下载。

## 升级

建议解压到独立目录。先备份旧配置，再复制 `Data/my.Config`。旧 CL 接口会自动迁移到 Paddle，原 Paddle 参数保留。新配置不再生成 CL 参数。

## 验证与限制

已完成 Release x64 构建、实际 OCR 回归、旧模型与字典校验，以及 WinForms 的 CL 配置迁移、Paddle 单菜单、设置保存重载和主窗口实际识别测试。

本机验证环境为 Windows Server x64 / .NET Framework 4.8 / VC++ 14.50。尚未完成 Windows 10/11、不同 DPI 和多硬件矩阵测试。原项目仍有编译警告及待重构代码，不将本次功能回归等同于全界面测试或真实场景准确率评测。

详细内容见 [架构与使用说明](架构与使用说明.md) 和根目录的升级说明。本发布只包含天若 OCR，不包含独立的 PDF 转 Word 验证软件。
