# 天若 OCR 1.4.2 · Paddle 精简版

原始项目：[wangfreexx/wangfreexx-tianruoocr-cl-paddle](https://github.com/wangfreexx/wangfreexx-tianruoocr-cl-paddle)。原始发布页：[上游 Releases](https://github.com/wangfreexx/wangfreexx-tianruoocr-cl-paddle/releases)。继续遵循 GPL-3.0 许可。

## 精简内容

- 删除旧 Paddle 中、英、日模型和自动回退分支，仅加载 PP-OCRv6 模型目录。
- 不再打包 `opencv_videoio_ffmpeg455_64.dll`。它是视频解码插件，截图识别不使用。
- 移除闲置的 Emgu UI、INI 解析器及显式 DiagnosticSource 包引用。
- 发布包排除未使用的 `Emgu.CV.Platform.NetFramework.dll`、`INIFileParser.dll`、`System.Diagnostics.DiagnosticSource.dll`、`System.Text.Encodings.Web.dll`、`zxing.presentation.dll`。
- 不再复制 `DLL/pinyin.txt`，拼音数据已嵌入主程序资源。
- 成品只附一份使用说明，完整中文文档、架构图和历史发布说明保留在仓库。
- 补回默认快门音 `Data/screenshot.wav`，用户配置仍不随包发布。
- 打包改为明确的运行文件清单，避免旧构建目录残留文件再次混入。

## 下载和运行

相对上一版成品，文件数从 49 减至 30，解压体积从约 135.3 MiB 减至 98.3 MiB，ZIP 从约 78.7 MiB 减至 54.9 MiB（减少约 30%）。这些数值不包含用户后续生成的配置。

下载 `TianruoOCR-Paddle-1.4.2-win-x64.zip`，完整解压后运行 `天若OCR文字识别.exe`。需要 Windows x64、.NET Framework 4.7.2 或更高版本及 VC++ v14 x64 运行库。

旧 Paddle 备用模型已删除，不能通过重命名 v6 模型目录自动回退。建议解压至新目录，按需迁移备份后的 `Data/my.Config`。不要直接把新文件覆盖到旧目录，否则旧文件仍会残留。

`cvextern.dll`、ONNX Runtime、四个模型/字典文件及截图、二维码、翻译功能所需依赖继续保留。单引擎仍需图像处理与推理运行库。
