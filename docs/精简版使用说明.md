# 天若 OCR 1.4.2 · Paddle 精简版

完整解压后运行 `天若OCR文字识别.exe`。运行需要 Windows x64、.NET Framework 4.7.2 或更新版本、Microsoft Visual C++ v14 x64 运行库，无需 Python。不要覆盖旧文件夹，建议使用独立的新目录。

本版只保留一套 PP-OCRv6 small 检测、识别及 PP-LCNet 方向分类模型，不再附带旧 Paddle 模型或语言专用备用模型。旧配置中的 CL 接口自动迁移至 Paddle，原 Paddle 参数继续保留。缺失模型需恢复模型文件，不能通过改名目录回退到旧模型。

删除了视频解码插件、未使用的程序集、独立拼音数据副本、设置截图及重复文档。拼音字典已嵌入程序。截图、结果编辑、复制、二维码和翻译入口保留；翻译需要自行配置并联网。`Data/screenshot.wav` 是默认快门音，请保留；`Data/my.Config` 是运行时创建的用户配置，不随包发布。

`cvextern.dll`、`onnxruntime.dll` 和 `models` 是识别必需文件。即使这些文件较大也不可单独删除。新版模型和推理运行库比原版大，单引擎不代表单文件程序。

逐文件校验见 `SHA256.json`。完整源码、详细文档及架构图见 [本仓库](https://github.com/gukey/tianruoocr-202610-local)。
